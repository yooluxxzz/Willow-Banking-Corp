# WILLOW BANKING CORP — COMPLETE DIGITAL BANKING & FINANCIAL PLATFORM UPGRADE

Upgrade the existing **Willow Banking Corp** project into a premium, modern, full-service digital banking and financial platform.

**IMPORTANT:** This is an upgrade of an existing project. Do NOT throw away existing functionality that already works. Preserve the existing architecture and working features where possible, while substantially improving the product design, UX, information architecture, visual identity, interactions, and financial capabilities.

The final result should feel like a serious next-generation financial institution combining the polish of a premium digital bank, the usability of a modern fintech app, and the depth of an investment platform.

Do NOT make it look like a generic banking template.

---

# 1. CORE PRODUCT VISION

Willow should feel like:

> **A complete financial ecosystem, not just a bank website.**

The customer should be able to use Willow for:

* Everyday banking
* Savings
* Cards

* Transfers
* International money
* Loans
* Credit
* Mortgages
* Business banking
* Stocks
* ETFs
* Funds

* Financial insights

Everything should feel like one coherent Willow ecosystem.

The experience should communicate:

**Trust + sophistication + simplicity + intelligence + security**

Avoid making Willow look like a crypto exchange, trading casino, or flashy startup.

The visual language should remain premium, calm, trustworthy, and institutional.

# 3. VISUAL DESIGN SYSTEM

Create a cohesive design system.

## Typography

Use a premium modern sans-serif typeface.

Typography hierarchy should be extremely clear:

* Large editorial hero typography
* Strong section headings
* Comfortable body text
* Clear financial numbers
* Small supporting labels
* Monospaced or tabular numerals where useful for financial data

Large numbers such as balances, portfolio values, rates, and stock prices should feel visually important.

## Color

Maintain Willow's existing brand colors if they are already established, but refine them into a professional design system.

Use:

* Primary brand color
* Secondary accent
* Neutral backgrounds
* Elevated card surfaces
* Strong text colors
* Muted secondary text
* Positive financial state
* Negative financial state
* Warning state
* Error state

Do NOT turn the entire interface into gradients.

Gradients should be subtle and intentional.

## Shape language

Use consistent:

* Border radius
* Card geometry
* Button geometry
* Input styling
* Shadows
* Borders
* Spacing

The interface should feel expensive without being ornamental.

```text

   ↓
Market Data Service
   ↓
yfinance
   ↓
Yahoo Finance data
```

Cache market data where appropriate.

Handle:

* API/data failures
* missing symbols
* rate limits
* stale data
* unavailable fields

when necessary.
